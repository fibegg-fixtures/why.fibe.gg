# Ефемерні середовища

Середовище на бренч або PR. Піднімається на push, живе скільки потрібно, випаровується після.

Реальне, full-stack середовище під кожну зміну, яку ти везеш — створюється автоматично, назване по бренчу, зноситься, коли PR закривається. Перестаєш сперечатись, "хто зараз сидить на staging-сервері", і починаєш просто шерити URL.

## Як це виглядає

- Відкрив PR → у його описі за хвилину з'являється URL
- У середовища своя база, свої черги, засіяні дані
- Авто-клінап, коли PR мерджиться або 7 днів простоює
- З розумом по витратах: idle-середовища скейляться до нуля

## Який зсув це запускає

- **Ревьюери клікають до того, як ставити LGTM** — code review стає product review
- **Дизайнери ітерують по реальному** — більше ніяких "але у Figma виглядало інакше…"
- **Саппорт відтворює баги** у копії з даними клієнта
- **Сейлз демонструє фічу**, яку ще не випустили, не блокуючи інженерів

## Коли обирати

Якщо у твоєї команди відкритих PR більше, ніж staging-слотів — це форма, яка вбиває чергу.
